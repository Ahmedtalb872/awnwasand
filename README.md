# المحجة البيضاء — Flutter / Dart

تطبيق تعليمي إسلامي عربي على Android والويب، مع واجهة ترحيب وملفات طلاب ودورات ولوحة إدارة، إضافة إلى مسارات التعلم الأساسية.

تعتمد الواجهات هوية الشعار الأصلي بألوان البنفسجي الداكن والوردي الهادئ والأبيض العاجي، مع اتجاه عربي من اليمين إلى اليسار. تعرض بطاقات الدورات وملف الطالب التقدم الفعلي؛ لا تتضمن أرقام المعاينة التصميمية.

[عرض التطبيق](https://ahmedtalb872.github.io/awnwasand/)

## تجربة التطبيق

بدون إعدادات Supabase، يعمل الرابط في **وضع تجريبي محلي** واضح داخل الواجهة:

- أنشئ ملفات طلاب مستقلة، أو تابع ملفًا موجودًا على الجهاز.
- اختر «تجربة لوحة الإدارة» لإضافة دورة باسم ووصف ومعلّم ومستوى، وحفظها كمسودة أو نشرها.
- افتح مواد الدورة وارفع فيديو MP4/WebM/MOV أو ملف PDF/Word/PowerPoint أو صورة، بحد 50 ميجابايت للملف.
- انتقل إلى ملف طالب وانضم إلى الدورة وشاهد الفيديو داخل التطبيق أو نزّل المرفقات وسجّل إتمام المواد.
- تعرض لوحة الإدارة ملفات الطلاب وتسجيلاتهم وتقدمهم في مواد الدورات.

بيانات التجربة تبقى على الجهاز ولا تظهر للآخرين. تحفظ مرفقات المتصفح في IndexedDB، وملفات الهاتف في مساحة التطبيق. حذف التطبيق أو بيانات الموقع قد يحذفها. الدخول إلى ملفات التجربة ليس نظام مصادقة ولا يستخدم للبيانات الحساسة.

## الحسابات والرفع المشترك عبر الإنترنت

أُضيف تكامل Supabase للحسابات وقاعدة البيانات والتخزين الخاص وصلاحيات الطلاب والمشرف. تعليمات التفعيل والمخطط موجودة في [supabase/README.md](supabase/README.md).

عند توفير إعدادات الخدمة، يسجّل الطلاب بحسابات بريدية وكلمات مرور. الطالب يرى ملفه والدورات المنشورة ومواد الدورات التي انضم إليها. المشرف وحده يدير الدورات وموادها ويطّلع على ملفات الطلاب. تمنع سياسات قاعدة البيانات الطالب من تغيير دوره أو إدارة المحتوى.

تحفظ تسجيلات الدورات وتقدم موادها عبر الإنترنت؛ تقدم اختبارات المسارات الأساسية يبقى محليًا ومفصولًا لكل طالب. GitHub Pages يستضيف الواجهة فقط. يلزم إعداد مشروع Supabase وتطبيق المخطط لتفعيل المشاركة بين الأجهزة. لم يُطبّق المخطط على مشروع خارجي أثناء هذا التغيير.

## الإعداد والتشغيل

يتطلب Flutter 3.29.3 وJava 17 وAndroid SDK لبناء Android:

```bash
flutter create --platforms=android,web --org com.awnwasand --project-name awnwasand .
flutter pub get
flutter run -d chrome
```

الأمر الأول يولّد أدوات المنصات دون --overwrite. لتشغيل نسخة متصلة:

```bash
flutter run --dart-define=SUPABASE_URL=https://your-project.supabase.co --dart-define=SUPABASE_ANON_KEY=your-public-key
```

استخدم المفتاح العام Publishable/anon فقط، ولا تستخدم service_role في Flutter أو المستودع. تعتمد مهام النشر على متغيري المستودع SUPABASE_URL وSUPABASE_ANON_KEY عند توفيرهما.

## التحقق والبناء

```bash
flutter analyze --no-fatal-infos
flutter test
flutter test --platform chrome test/media_web_test.dart
flutter build apk --debug
flutter build web --release --base-href /awnwasand/
```

تتحقق الاختبارات من تصحيح الدروس وعزل تقدم الطلاب وإنشاء الدورات وموادها ومنع الإدارة من حساب الطالب والتسجيل والتقدم وشاشات الترحيب والإدارة وتخزين المرفقات في IndexedDB داخل Chrome. تنفّذ GitHub Actions الفحوص والبناء. توقيع Android الحالي للتجربة؛ النشر في المتجر يحتاج توقيع إصدار خاص.

## البنية

- lib/academy_ui.dart: الترحيب وملفات الطلاب والإدارة والدورات والرفع ومشغّل الفيديو.
- lib/academy.dart: العمليات والتكامل السحابي/التجريبي.
- lib/academy_models.dart: نماذج الطلاب والدورات والمواد والتسجيلات.
- lib/media_store*: تخزين ملفات المتصفح والهاتف.
- lib/main.dart وmodels.dart وlearning_store.dart: المسارات والاختبارات وتقدم كل طالب.
- assets/curriculum.json: 6 مسارات و12 درسًا موثّقًا و24 سؤالًا.
- supabase/schema.sql: الجداول وسياسات RLS والتخزين الخاص.

المحتوى الأساسي تمهيدي ويحتاج مراجعة معلّم قبل اعتماده. سجلات الإنجاز ليست شهادات علمية معتمدة. إتمام مواد الدورة يقرّ به الطالب؛ لا يدّعي التطبيق التحقق من مشاهدة الفيديو كاملة.
