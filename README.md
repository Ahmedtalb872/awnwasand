# عون وسند — Flutter / Dart

تطبيق تعليمي إسلامي بواجهة عربية RTL، مبني بلغة **Dart** باستخدام **Flutter**. يستهدف Android والويب، ويعمل دون خادم Python.

## الوظائف

- ستة مسارات و12 درسًا موثّقًا في العقيدة والقرآن والعبادات والحديث والسيرة والأخلاق.
- 24 سؤالًا مع تصحيح وشرح؛ النجاح من 70٪، مع حفظ أفضل نتيجة وعدد المحاولات.
- مكتبة للبحث والتصفية، ومحفوظات، وملف متعلم وهدف يومي وسجلات إنجاز للمسارات.
- الدروس والاختبارات متاحة دون إنترنت؛ روابط المصادر تُفتح في المتصفح وتتطلب الاتصال.
- حفظ محلي باستخدام SharedPreferences؛ لا توجد حسابات بريدية أو مزامنة بين الأجهزة. حذف التطبيق أو بيانات المتصفح قد يحذف التقدم.

## الإعداد والتشغيل

ثبّت Flutter 3.29.3 (يتضمن Dart) وAndroid SDK وJava 17. من جذر المشروع:

```bash
flutter create --platforms=android,web --org com.awnwasand --project-name awnwasand .
flutter pub get
flutter run
```

الأمر الأول يولّد أدوات المنصات المحلية، ومنها Gradle wrapper، دون استخدام `--overwrite` كي يحافظ على ملفات Dart المخصصة. أُرفقت إعدادات Android والويب الأساسية بالمستودع. اختر هاتف Android أو محاكيًا عبر `flutter devices`، أو شغّل الويب:

```bash
flutter run -d chrome
```

## التحقق وبناء التطبيق

```bash
dart format lib test
flutter analyze --no-fatal-infos
flutter test
flutter build apk --debug
flutter build web --release
```

ملف Android التجريبي: `build/app/outputs/flutter-apk/app-debug.apk`. تُنفّذ GitHub Actions التحليل والاختبارات وبناء Android والويب، وتُرفق APK عند نجاح المهمة. لا يُنشَر التطبيق تلقائيًا في المتجر.

بناء إصدار للنشر يتطلب إعداد مفتاح توقيع خاص بدل توقيع debug الحالي. دعم iOS يمكن تهيئته عبر `flutter create --platforms=ios --org com.awnwasand .` على macOS، ثم إعداد Xcode والتوقيع؛ لم يُرفق مشروع iOS في هذه النسخة.

## البنية

- `lib/main.dart`: واجهة Material 3، التنقل، الدروس والاختبارات.
- `lib/models.dart`: نماذج Dart وتصحيح الاختبارات.
- `lib/learning_store.dart`: التقدم والأهداف والمحْفوظات والحفظ المحلي.
- `assets/curriculum.json`: المحتوى والمراجع والأسئلة.
- `test/`: اختبارات المحتوى والتصحيح والحفظ والواجهة.
- `android/` و`web/`: إعدادات المنصات.

هذه نسخة أولى بمنهج تمهيدي محدود، وليست موسوعة أو مصدر فتاوى. تحتاج الشروح مراجعة تربوية وشرعية قبل اعتمادها رسميًا، وسجلات الإنجاز ليست شهادات علمية معتمدة. الأسئلة والإجابات مخزنة محليًا لأغراض المراجعة الذاتية؛ الاختبارات الرسمية تحتاج تصحيحًا موثوقًا في خدمة خلفية.

## حالة التحقق

بيئة إعداد هذا التغيير لا تتضمن Flutter أو Dart، لذلك لم تُنفَّذ أوامر التحليل والاختبارات والبناء محليًا. أُضيفت اختبارات Dart وWidget ومهمة CI لتنفيذها في بيئة Flutter؛ ينبغي التأكد من نتائجها قبل دمج التغيير.
