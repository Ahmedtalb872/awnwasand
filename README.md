# عون وسند — تطبيق تعليمي إسلامي

تطبيق ويب عربي متجاوب يعمل على الهاتف والحاسوب، مبني ببايثون وSQLite دون مكتبات خارجية. يحوّل المشروع من أداة رسائل SMS إلى تجربة تعلم متكاملة في القراءة والمراجعة ومتابعة الإنجاز.

## المزايا

- ستة مسارات: الإيمان، القرآن والتدبر، العبادات، الحديث، السيرة، والأخلاق.
- 12 درسًا تمهيديًا، ومراجع مباشرة للقرآن وصحيحَي البخاري ومسلم، وتطبيق عملي لكل درس.
- 24 سؤالًا مع تصحيح على الخادم وشرح الإجابات؛ النجاح من 70٪.
- إنشاء حساب وتسجيل دخول وخروج؛ تخزين كلمات المرور باستخدام PBKDF2 وجلسات محدودة المدة.
- حفظ التقدم وأفضل نتيجة وعدد المحاولات في SQLite، وفصل بيانات كل متعلم.
- مكتبة قابلة للبحث والتصفية، ومحفوظات، وهدف يومي، وسجلات إنجاز للمسارات قابلة للطباعة.
- واجهة RTL، تصميم متجاوب، دعم لوحة المفاتيح، وحالات تحميل وخطأ ونتائج فارغة.

## التشغيل

يتطلب Python 3.10 أو أحدث فقط:

```bash
python app.py
```

افتح `http://127.0.0.1:5000`. لا تحتاج إلى إعداد مفتاح SMS أو ملف `.env`. تصفّح الدروس دون حساب، وأنشئ حسابًا لحفظ نتائج الاختبارات والمحفوظات. تُنشأ قاعدة البيانات تلقائيًا في `data/learning.sqlite3`؛ احتفظ بنسخة احتياطية منها.

إعدادات اختيارية عبر متغيرات البيئة الفعلية (لا يُقرأ `.env` تلقائيًا):

```bash
HOST=0.0.0.0 PORT=5000 APP_DB=/path/to/learning.sqlite3 python app.py
```

للنشر العام، شغّل خلف وكيل HTTPS مع `COOKIE_SECURE=1`، وحدّد اسم المضيف المسموح في الوكيل، وأضف حدود طلبات مناسبة. خادم المكتبة القياسية مناسب للتشغيل المحلي والتجربة؛ التشغيل الإنتاجي واسع النطاق يتطلب مراجعة البنية. التطبيق لا يرسل رسائل SMS ولا يتصل بأي خدمة خارجية تلقائيًا؛ فتح روابط المراجع هو إجراء يقوم به المستخدم.

## التحقق

```bash
python -m unittest discover -s tests -v
node --check static/app.js
```

تتحقق الاختبارات من التسجيل والدخول، وعزل بيانات المستخدمين، وحساب النتائج وحفظها، وعدم تكرار الإنجاز، والمحْفوظات والأهداف، وحماية CSRF ومنع المسارات غير المسموحة.

## بنية المشروع

- `app.py`: الخادم، الحسابات، الجلسات وواجهات البيانات.
- `curriculum.py`: المحتوى والمراجع والأسئلة؛ لا تُرسل الإجابات الصحيحة في فهرس الدروس.
- `static/`: واجهة التطبيق.
- `tests/`: اختبارات تكامل HTTP باستخدام قاعدة مؤقتة.
- `legacy/`: أدوات الرسائل السابقة، محفوظة للرجوع إلى النسخة القديمة؛ ليست جزءًا من التطبيق التعليمي.

## نطاق المحتوى

هذه نسخة أولى قابلة للتشغيل بمنهج تمهيدي محدود، وليست موسوعة كاملة أو مصدر فتاوى. الشروح صياغات تعليمية منفصلة عن النصوص الأصلية المرتبطة. ينبغي مراجعة المحتوى تربويًا وشرعيًا مع معلّم قبل اعتماده رسميًا. سجلات الإنجاز داخل التطبيق ليست شهادات علمية معتمدة.

لا تتضمن هذه النسخة المصحف كاملًا، أو الصوتيات، أو حساب مواقيت الصلاة، أو لوحة إدارة، أو استعادة كلمة المرور بالبريد. يمكن إضافة المحتوى بتوسيع `curriculum.py` مع الحفاظ على معرّفات الدروس القديمة وذكر مصادر دقيقة.
